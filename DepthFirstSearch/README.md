# Depth First Search

This project demonstrates the **Depth-First Search (DFS) algorithm** for traversing a graph.

DFS explores a graph by going as deep as possible along each branch before backtracking. It can be used to explore connected nodes and solve various graph traversal problems.

## How It Works

1. Start from a selected node.
2. Mark the current node as visited.
3. Visit an unvisited neighboring node.
4. Continue exploring deeper into the graph.
5. When there are no unvisited neighbors, backtrack.
6. Continue until all reachable nodes have been visited.

## Complexity

* **Time Complexity:** O(V + E)
* **Space Complexity:** O(V)

Where `V` is the number of vertices and `E` is the number of edges.
